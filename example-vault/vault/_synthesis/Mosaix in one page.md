# Mosaix in one page

A Mosaix vault is a folder of Markdown notes. Each note answers one question and carries nine keys above the body ([[§3 The note]]). Notes link with wikilinks; no orphans, no broken links. Content that must be read together is joined by a composed document, never copied ([[§6 Composed documents]]). Eight rules ([[§7 Rules]]): five checked from files, three commitments. Everything about producing, enriching, searching or editing notes is an implementation ([[§8 Out of scope]]).
