# Template — MOC

Copy this file to start a map of content ([[§5 Vault structure]]). Structure: one paragraph per area, then the links.

- **One paragraph per area.** Name the area in a sentence or two: what it covers, why it matters, where to start.
- **Then the links.** After the paragraph, list the wikilinks to the notes in that area, in reading order.
- **Stay reachable.** Every note in the vault should be reachable from a MOC, directly or through another MOC ([[R3 Connectedness]]).
