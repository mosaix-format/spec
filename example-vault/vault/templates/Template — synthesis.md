# Template — synthesis

Copy this file to start a synthesis note that lives in `_synthesis/` ([[§5 Vault structure]]). It must link every note it summarises.

- **Condense one area** into a text a reader or a machine can consume alone, before any task in that area.
- **Link every note it summarises.** A synthesis that leaves a note out is incomplete, not concise ([[R5 Composition over duplication]]).
- **It is not the source.** When the synthesis disagrees with a note, the note wins; the synthesis is stale.
- See [[Mosaix in one page]] in this vault for a working synthesis.
