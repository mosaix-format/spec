# §1 Purpose

Three goals. A machine retrieves one note ([[§3 The note]]) and has enough context to act. A person reads many notes as one document ([[§6 Composed documents]]). Contradictions are recorded ([[R6 Record, don't resolve]]), superseded notes are marked, automated writes are proposed. The format is deliberately small.
