# §5 Vault structure

Folders are free; numbered prefixes are a reading order. Reserved: `_meta/` (this vault's [[Conventions]] and [[Open questions]]), `_synthesis/` (see [[Mosaix in one page]]), `_inbox/` (nothing there counts). The meta note declares folders, reliability convention, domain keys and the tag taxonomy ([[R4 Declared taxonomy]]).
