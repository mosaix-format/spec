# Mosaix Format v1.0 — Rules (§7)

R1–R5 are verifiable from files. R6–R7 are process rules the meta note commits to.

- **R1 — Atomicity.** One note answers one question.
- **R2 — Self-description.** Every note carries the CORE frontmatter (§3.1).
- **R3 — Connectedness.** No orphans, no broken links (§4).
- **R4 — Declared taxonomy.** Every tag and every domain key is declared in the meta note (§5.4).
- **R5 — Composition over duplication.** Content that must be read together is joined with a composed document (§6) or a synthesis (§5.2), never copied.
- **R6 — Record, don't resolve.** A contradiction is entered in the open-questions ledger with both versions; no one picks a winner silently.
- **R7 — Supersede, don't delete.** A note that is no longer valid is marked superseded and left in place; deletion is reserved for notes created in error.

**R8 — Propose, don't apply (agent workflow recommendation, non-normative).** Automated processes SHOULD write to a branch or staging area that a human reviews; SHOULD NOT write directly to the vault's main line. Not verified by the checker.
